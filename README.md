# 朗读合辑

> 📖 第一次使用？请直接双击打开 **`使用说明.html`**——那是一页纸的图文上手说明，照着点就行。

**把散落的朗读音频，变成一支值得回看的合辑。**

书店、课堂、图书馆或线上阅读社群，常常会收到许多朗读投稿。逐个找开头、剪片段、调音量、拼视频，很容易占掉组织者的时间。朗读合辑帮你完成这些重复工作：把本期音频放进一个文件夹，双击制作，就能得到一支待审核的视频和一份核对清单。

朗读者可以是孩子，也可以是成年人；可以读得熟练，也可以正在练习；可以使用不同语言、口音和节奏。这个工具只寻找录音中有人声的部分，**不会给谁的朗读打分**。最后收录什么、是否分享，由人决定。

## 它会帮你做什么

- 从每个音频文件里找一段有人声的内容，尽量避开开头的长时间空白。
- 调整片段音量，按文件名顺序拼成一支视频。
- 默认成片不超过 4 分钟。选段总时长超出时，自动缩短较长片段，尽量保留每份有效投稿；短片段保留原长，多出的时间分给其他片段。
- 用自带的海边日落图片作背景；你也可以换成自己的图片。
- 生成核对清单，列出入片文件、选取的时间，以及需要留意的问题。
- 遇到重复或损坏的文件时，在清单里说明，并继续处理其他文件。

音频和视频都在你的电脑上处理。程序不会登录微信、读取聊天记录、上传音频或替你发布视频。

## 五步开始

1. 从 [Python 官网](https://www.python.org/downloads/)安装 **Python 3.13**；Windows 安装时勾选 **Add python.exe to PATH**，再点 **Install Now**。
2. 下载并解压这个项目，Mac 双击 `首次安装-Mac.command`，Windows 双击 `首次安装-Windows.bat`，等窗口显示“安装完成”。
3. 把这次要收录的音频放进 `待处理音频` 文件夹；支持 `.m4a`、`.mp3`、`.wav`、`.aac` 和 `.mp4`。
4. Mac 双击 `制作视频-Mac.command`，Windows 双击 `制作视频-Windows.bat`，等窗口显示“制作完成”。
5. 打开 `成片` 文件夹，先看核对清单，再试听“待审核”的视频，确认后自行决定是否分享。

首次安装需要联网。日常制作不需要打开 Codex，也不用单独安装 Node.js、Whisper 转写模型或视频处理软件。做下一期前，请先把上一期放在 `待处理音频` 的文件移出；原文件如果还保留在微信或你的备份位置，不会受到影响。

**Windows 已装好，只更新到 4 分钟版：**收到更新 ZIP 后，先“全部解压”，关闭正在制作的视频窗口，双击 `双击更新.bat`，在弹窗里选原来的 `制作视频-Windows.bat`。看到“更新成功”后仍使用原来的入口，不需要重新安装。更新只替换两个程序文件，旧版自动存进 `更新备份`；音频、成片和运行环境保留。已有视频需重新制作才会变短。更新与失败恢复测试已通过；已根据 Windows 实际运行截图确认更新入口显示成功。

> **目前的验证情况：**原有完整制作流程已在 Mac 和 Windows 11 上测试。本次新增的 4 分钟限制已在 Mac 用人工音频验证，尚未在 Windows 实机复测。欢迎反馈安装或制作时遇到的问题。

## 分享前花一点时间检查

请确认每位朗读者都有被收录，试听每段的开头、结尾和交接处，并核对文件名与朗读者的对应关系。为控制在 4 分钟内而缩短的选段，会在核对清单里提醒；投稿越多，每段可能越短。人声检测能避开部分空白，却不能理解文章内容，也不能保证每次都停在完整句子上；轻声朗读、背景声音或损坏录音也可能影响结果。

如果要公开分享含有他人声音的作品，尤其是未成年人的投稿，请先确认相关参与者愿意被这样分享。

## 常见问题

**能直接从微信群里拿音频吗？** 这个公开版只处理你放进 `待处理音频` 的文件。请先在聊天软件中下载投稿；它不会读取聊天数据库，也无法知道还有哪些文件没有下载。

**能自动挑出“读得最好”的一句吗？** 目前不能。程序检测哪里有人声，不根据口音、流利度、情绪或文章内容评判朗读者。

**可以换背景吗？** 可以。把你有权使用的图片替换 `素材/海边日落.png`，保持这个文件名即可；程序会自动裁切到视频画面大小。

**制作失败怎么办？** 保留窗口里的报错，先确认音频能播放、文件确实在 `待处理音频` 中，并查看安装是否完成。制作失败时，请不要把上一次的视频当作本次成片。

Windows 会先检查备用的 Python 是否真的能运行；只有系统自带的安装快捷入口，或版本早于 3.11，都不能通过检查。请按使用说明完成安装。若程序已经开始运行却制作失败，请把工具文件夹里的 `运行日志.log` 交给帮你安装的人；其中可能包含电脑路径和音频文件名，请不要直接公开上传。

## 一起改进

欢迎用 Issue 或 Pull Request 反馈：步骤哪里看不懂、哪些声音没有被正确截取、Windows 上哪里运行不顺。请用自己录制或人工生成的测试音频说明问题，**不要上传他人的真实投稿、聊天记录、孩子的声音或本机账号文件**。

维护者可以运行 `python -m unittest discover -s tests -v` 检查时长分配、核对清单、启动和报错处理；GitHub 也会在 Windows 上自动跑这些检查。测试只使用人工构造的数据和故障，不需要真实投稿。

项目代码与随项目提供的背景图片按 [MIT License](LICENSE) 开放。所用的第三方软件由首次安装脚本从各自的发布渠道安装，不包含在本仓库里。

维护者可用 `python tools/build_windows_update.py --output outputs/朗读合辑-4分钟更新包.zip` 生成小更新包，只包含更新入口、两个程序文件及校验清单，不包含环境、投稿或成片。
