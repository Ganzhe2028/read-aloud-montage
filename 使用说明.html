朗读合辑 · 使用说明

把本期朗读音频放进一个文件夹，双击一下，自动拼成一支视频。
不用懂电脑技术，照着点就行。

一、准备工作（只在第一次用时做一次）

1安装 Python（一个免费的基础软件）

Windows 电脑：

点击下载 Python（Windows 版）python-3.13.15-amd64.exe · 约 27 MB · 来自 python.org 官网
  1. 下载好后，双击打开这个文件。
  2. 最重要的一步：安装窗口最下面有一个小方框 ☑ Add python.exe to PATH，先勾上它。
  3. 再点 Install Now，等它装完，点 Close。

注：绝大多数电脑用上面这个链接。只有 Surface Pro X 等少数 ARM 芯片设备，才改用 这个 ARM 版链接。

苹果电脑（Mac）：

点击下载 Python（Mac 版）python-3.13.15-macos11.pkg · 约 45 MB · 来自 python.org 官网
  1. 下载好后，双击打开，一路点 继续 → 同意 → 安装。
  2. 中途会要求输入一次开机密码，输入时屏幕不显示字符，这是正常的，输完按回车。
  3. 看到“安装成功”后点关闭。

2解压工具包

把收到的压缩包解压，得到一个文件夹（里面就是本说明所在的这套文件）。

⚠️ 请把整个文件夹放在桌面或“文档”里使用，不要只拖出其中几个文件——它们要待在一起才能工作。

3首次安装（需要联网，约 5–15 分钟）

Windows：双击 首次安装-Windows.bat

如果弹出蓝色窗口“Windows 已保护你的电脑”：点 更多信息，再点 仍要运行。这是 Windows 对陌生文件的常规提醒，不是病毒。

Mac：双击 首次安装-Mac.command

如果提示“无法打开，因为无法验证开发者”：在这个文件上点右键 → 选 打开 → 在弹窗里再点一次 打开。只需这样操作一次，以后双击即可。
✅ 窗口里最后显示“安装完成”才算装好，按回车关闭窗口。以后使用不用再装。
二、每期制作（每次这样用）

4把本期音频放进“待处理音频”文件夹

  1. 微信群里的投稿，请先在电脑微信里下载保存到电脑上。
  2. 把本期要收录的音频文件放进 待处理音频 文件夹；支持 .m4a .mp3 .wav .aac .mp4。
  3. 上一期留在里面的文件，请先移走。

5双击制作

Windows：双击 制作视频-Windows.bat　　Mac：双击 制作视频-Mac.command

窗口显示“正在识别人声并制作视频”，耐心等它跑完（音频多的话要几分钟）。看到“制作完成”后，成片 文件夹会自动打开。

6检查后再分享

  1. 先打开 成片 里的“核对清单”网页，看本期收了哪些文件、有没有被跳过的。
  2. 再试看视频，重点听每段的开头、结尾和两个人交接的地方。
  3. 确认每位投稿人都收录了、内容没问题，再自行决定怎么分享。
工具只负责找出“有人声”的片段，不会判断读得好不好、句子完不完整。最终收录什么，由您决定。

卡住了怎么办

把整个窗口拍下来（手机拍照即可），发给帮您安装的人，并说一下您做到第几步了。

如果某次制作失败，请不要把上一次做好的旧视频当成这次的结果——旧视频还留在“成片”文件夹里，注意看文件日期。

所有音频只在您的电脑上处理，不会上传到任何地方。
工具不评判朗读的好坏，任何年龄、口音和语言的声音都一样欢迎。
